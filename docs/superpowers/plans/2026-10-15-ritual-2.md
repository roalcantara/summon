# Ritual 2.0 + Visual Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the ritual as a two-stage "lock, then chant" state machine, with voiced-syllable detection, a grace period, a vector sigil that inks itself and a cinematic climax. Lift Grimoire (hero pager) and Profile (cut-out hero) to match, adding generated audio, haptics, AGSL FX and gyro parallax.

**Architecture:** Pure Kotlin core (`LatinSyllables`, `VoiceAnalyzer`, `RitualEngine` reducer emitting `RitualEffect`s, `SigilPaths`) is JVM-unit-tested. `RitualViewModel` feeds the engine one 20 ms tick per mic frame (`PcmSource` → `VoiceAnalyzer`) plus the latest heading. It exposes `StateFlow<RitualUiState>` and `SharedFlow<RitualEffect>`. Compose renders the state; `RitualFeedback` turns effects into haptics and sounds. Screens share the demon cut-out through `SharedTransitionLayout`.

**Tech Stack:** AGP 9.4.1 (Kotlin 2.2.10), Compose BOM 2026.09.00 + Material 3 + Foundation pager, navigation-compose 2.10.2, lifecycle 2.11.0, `android.graphics.RuntimeShader` (API 33+), `SoundPool`/`MediaPlayer`, JUnit 4 + kotlinx-coroutines-test 1.11.0. Python 3 stdlib generators in `tools/`; `cwebp`; `uvx` (fonttools) for fonts. Spec: `docs/superpowers/specs/2026-10-15-ritual-2-design.md`.

```markdown
# 0008 — Ritual 2.0 rules

- Date: 2026-10-15
- Status: Accepted (supersedes ADR-0007)

## Context
Play-testing the first port showed that the ritual felt arbitrary. Any noise above an
RMS threshold for 2 s completed a phrase, regardless of what was said. Drifting off
the heading silently wiped all progress, and nothing on screen reacted to the voice.

## Decision
The ritual is a pure state machine ticked every 20 ms (`RitualConfig.FRAME_MS`):
Seeking → Locking → Chanting ⇄ Wavering → Climax → Done.
- **Lock:** staying within the demon's heading tolerance (±20°) for 600 ms locks
  the ritual. Leaving earlier returns to Seeking.
- **Syllables:** each phrase needs as many lit syllables as `LatinSyllables.count`
  gives (diphthongs AE/OE/AU/EI/EU are one nucleus; "QU" is a consonant). A syllable
  lights on a voiced onset at least 120 ms after the previous lit syllable, or after
  350 ms of continuous voicing. Unvoiced frames pause; nothing decays.
- **Voiced:** RMS > 1 200 (PCM16) and a normalized autocorrelation peak ≥ 0.5 for
  70–400 Hz over the last 40 ms. **Onset:** a voiced frame ≥ 1.8 × the minimum RMS of
  the previous 100 ms while the detector is armed; it re-arms after an unvoiced frame
  or a dip below 0.6 × the peak since the last onset.
- **Grace:** leaving tolerance while chanting enters Wavering. Returning within 1.5 s
  loses nothing; otherwise only the current phrase's lit syllables are lost and the
  player must lock again.
- **Climax:** after phrase 4, input is ignored for 2.5 s, then the demon is summoned.
All numbers are global tuning in `RitualConfig`, not demon data (ADR-0006).

## Consequences
Claps, taps and wind no longer count, and slurred or held chanting still progresses
(slower). Word recognition stays a non-goal. Thresholds may need per-device tuning;
change `RitualConfig` and note it here.
```

```markdown
# 0009 — Vector sigils with ink progress

- Date: 2026-10-15
- Status: Accepted

## Context
Stitch could not render a correct Asmodeus sigil (its rim spelled "ASTAROTH"), and
the Astaroth PNG was not accurate either. PNG sigils with baked backgrounds also
can't be tinted, scaled crisply or animated per stroke.

## Decision
Sigils are stroke-only vector paths traced from public-domain/CC0 sources:
Asmodeus from Wikimedia Commons `File:Seal_of_Asmodeus.svg` (CC0), Astaroth from
`File:Astaroth_Seal.svg` (public domain; Mathers & Crowley 1904). Sources live in
`art/sigils/<id>.svg` (viewBox `0 0 100 100`, groups `ink-1`…`ink-4`, one contour
per path). `tools/sigil_to_raw.py` converts them to `res/raw/sigil_<id>.txt`. The
outer rings and rim letters (the demon's name) are drawn in code.
The sigil **inks itself** as the chant progresses:
`inkProgress = (completed phrases + lit/syllables) / 4`; group *g* inks over
[(g−1)/4, g/4]. It is tinted with the demon accent and glows with the live mic level.

## Consequences
Replaces the opacity steps 0.10/0.25/0.50/0.75/1.00 (PRODUCT.md "Sigil", ADR-0005
consequence). `sigil_astaroth.webp` is retired. A new demon needs one SVG traced into
the same format.
```

```python
#!/usr/bin/env python3
"""Generate the ritual sound set as 16-bit mono WAVs (Ritual 2.0 spec, section 6).

Original synthesized work, dedicated to the public domain (CC0).
Usage: python3 -I tools/gen_audio.py app/src/main/res/raw
"""
import math
import os
import random
import struct
import sys
import wave

RATE = 22050
TAU = 2 * math.pi
BED_SECONDS = 8.0  # every bed frequency is a multiple of 1/8 Hz, so the loop is seamless


def silence(seconds):
    return [0.0] * int(seconds * RATE)


def mix(buf, other, start=0.0, gain=1.0):
    s0 = int(start * RATE)
    for i, x in enumerate(other):
        j = s0 + i
        if j >= len(buf):
            break
        buf[j] += gain * x
    return buf


def lowpass(samples, cutoff):
    """One-pole low-pass; `cutoff` is Hz or a function of time in seconds."""
    y = 0.0
    out = []
    for i, x in enumerate(samples):
        fc = cutoff(i / RATE) if callable(cutoff) else cutoff
        y += (1 - math.exp(-TAU * fc / RATE)) * (x - y)
        out.append(y)
    return out


def tone(freq, seconds, partials, attack=0.01, decay=None, vibrato=0.0):
    out = []
    phase = 0.0
    for i in range(int(seconds * RATE)):
        t = i / RATE
        env = min(1.0, t / attack)
        if decay:
            env *= math.exp(-t / decay)
        phase += TAU * freq * (1 + vibrato * math.sin(TAU * 5.5 * t)) / RATE
        out.append(env * sum(a * math.sin(k * phase) for k, a in partials))
    return out


def bell(freq, seconds=1.6):
    parts = ((1.0, 1.0, 1.2), (2.76, 0.5, 0.6), (5.40, 0.25, 0.35), (8.93, 0.12, 0.2))
    out = []
    for i in range(int(seconds * RATE)):
        t = i / RATE
        s = sum(a * math.exp(-t / d) * math.sin(TAU * freq * r * t) for r, a, d in parts)
        out.append(s * min(1.0, t / 0.004))
    return out


def bed_asmodeus():
    """Warm low drone (A1 + fifth) with slow tremolo and faint fire crackle."""
    n = int(BED_SECONDS * RATE)
    drone = []
    for i in range(n):
        t = i / RATE
        trem = 0.8 + 0.2 * math.sin(TAU * 0.25 * t)
        drone.append(trem * (math.sin(TAU * 55 * t) + 0.6 * math.sin(TAU * 110 * t)
                             + 0.5 * math.sin(TAU * 82.5 * t) + 0.2 * math.sin(TAU * 165 * t)
                             + 0.1 * math.sin(TAU * 220 * t)))
    rng = random.Random(32)
    crackle = [0.0] * n
    tail = int(0.06 * RATE)  # keep the loop seam clean
    for _ in range(int(BED_SECONDS * 14)):
        s = rng.randrange(0, n - tail)
        for k in range(int(0.004 * RATE)):
            crackle[s + k] += rng.uniform(-1, 1) * math.exp(-k / (0.001 * RATE))
    crackle = lowpass(crackle, 3000.0)
    return [d + 0.6 * c for d, c in zip(drone, crackle)]


def bed_astaroth():
    """Eerie detuned minor pad (A, C, E) with a slow high shimmer."""
    voices = ((110.0, 1.0), (110.25, 0.8), (130.875, 0.7), (131.125, 0.6), (164.875, 0.5), (165.0, 0.4))
    out = []
    for i in range(int(BED_SECONDS * RATE)):
        t = i / RATE
        pad = sum(a * (math.sin(TAU * f * t) + 0.3 * math.sin(TAU * 2 * f * t) + 0.1 * math.sin(TAU * 3 * f * t))
                  for f, a in voices)
        lfo = 0.5 + 0.5 * math.sin(TAU * 0.125 * t)
        shimmer = lfo * (0.25 * math.sin(TAU * 880 * t) + 0.15 * math.sin(TAU * 1046.625 * t))
        out.append(pad + shimmer)
    return out


def lock():
    """Low thud with a falling pitch, plus a short high shimmer."""
    out = []
    phase = 0.0
    for i in range(int(0.9 * RATE)):
        t = i / RATE
        phase += TAU * (50 + 70 * math.exp(-t / 0.05)) / RATE
        out.append(math.sin(phase) * math.exp(-t / 0.25) * min(1.0, t / 0.003))
    return mix(out, bell(1760.0, 0.6), start=0.02, gain=0.25)


def riser():
    """~2.2 s noise + pitch sweep that swells into the climax."""
    seconds = 2.2
    n = int(seconds * RATE)
    rng = random.Random(29)
    hiss = lowpass([rng.uniform(-1, 1) for _ in range(n)], lambda t: 300 + 5000 * (t / seconds) ** 2)
    out = []
    phase = 0.0
    for i in range(n):
        p = i / n
        phase += TAU * 200 * (6 ** p) / RATE
        out.append(p * p * (0.5 * math.sin(phase) + 0.25 * math.sin(2 * phase) + 0.9 * hiss[i]))
    return out


def boom():
    """Sub hit with a long tail and a short noise thump."""
    out = []
    phase = 0.0
    for i in range(int(2.0 * RATE)):
        t = i / RATE
        phase += TAU * (40 + 60 * math.exp(-t / 0.08)) / RATE
        out.append(math.sin(phase) * math.exp(-t / 0.7) * min(1.0, t / 0.002))
    rng = random.Random(66)
    thump = lowpass([rng.uniform(-1, 1) * math.exp(-(i / RATE) / 0.03) for i in range(int(0.2 * RATE))], 900.0)
    return mix(out, thump, gain=0.8)


def tada():
    """Brassy rising arpeggio and final chord (C5 E5 G5 C6)."""
    brass = ((1, 1.0), (2, 0.6), (3, 0.45), (4, 0.3), (5, 0.2), (6, 0.12))
    buf = silence(1.6)
    for k, f in enumerate((523.25, 659.25, 783.99)):
        mix(buf, tone(f, 0.18, brass, attack=0.015, decay=0.12), start=0.1 * k, gain=0.5)
    for f in (523.25, 659.25, 783.99, 1046.50):
        mix(buf, tone(f, 1.25, brass, attack=0.03, decay=0.6, vibrato=0.004), start=0.33, gain=0.3)
    fade = int(0.2 * RATE)
    for i in range(fade):
        buf[len(buf) - fade + i] *= (fade - i) / fade
    return buf


# A minor pentatonic, one step higher per phrase.
CHIMES = (440.0, 523.25, 587.33, 659.25)

SOUNDS = {
    "bed_asmodeus": (bed_asmodeus, 0.6),
    "bed_astaroth": (bed_astaroth, 0.6),
    "chime_1": (lambda: bell(CHIMES[0]), 0.7),
    "chime_2": (lambda: bell(CHIMES[1]), 0.7),
    "chime_3": (lambda: bell(CHIMES[2]), 0.7),
    "chime_4": (lambda: bell(CHIMES[3]), 0.7),
    "lock": (lock, 0.85),
    "riser": (riser, 0.7),
    "boom": (boom, 0.9),
    "tada": (tada, 0.8),
}


def write(path, samples, peak):
    top = max(abs(x) for x in samples) or 1.0
    data = [int(32767 * peak * x / top) for x in samples]
    with wave.open(path, "wb") as out:
        out.setnchannels(1)
        out.setsampwidth(2)
        out.setframerate(RATE)
        out.writeframes(struct.pack("<%dh" % len(data), *data))


def main(out_dir):
    for name, (make, peak) in SOUNDS.items():
        write(os.path.join(out_dir, name + ".wav"), make(), peak)
        print(name)


if __name__ == "__main__":
    main(sys.argv[1])
```

```python
#!/usr/bin/env python3
"""Convert a stroke-only sigil SVG (art/sigils/*.svg) to the app's raw format (ADR-0009).

The SVG has viewBox "0 0 100 100" and groups <g id="ink-1"> ... <g id="ink-4">, each
holding <path d="..."> elements in draw order. Every path must be one contour (exactly
one moveto) so PathMeasure sees its full length.
Output: one line per path, "<group> <path-data>".
Usage: python3 -I tools/sigil_to_raw.py art/sigils/asmodeus.svg app/src/main/res/raw/sigil_asmodeus.txt
"""
import re
import sys
import xml.etree.ElementTree as ET

NS = "{http://www.w3.org/2000/svg}"


def convert(svg_path):
    root = ET.parse(svg_path).getroot()
    if root.get("viewBox") != "0 0 100 100":
        raise SystemExit(f"{svg_path}: viewBox must be '0 0 100 100'")
    lines = []
    for group in root.iter(NS + "g"):
        match = re.fullmatch(r"ink-([1-4])", group.get("id", ""))
        if not match:
            raise SystemExit(f"{svg_path}: unexpected group id {group.get('id')!r}")
        for path in group.iter(NS + "path"):
            d = " ".join(path.get("d", "").split())
            if len(re.findall(r"[Mm]", d)) != 1:
                raise SystemExit(f"{svg_path}: path must be exactly one contour: {d}")
            lines.append(f"{match.group(1)} {d}")
    if {int(line.split(" ", 1)[0]) for line in lines} != {1, 2, 3, 4}:
        raise SystemExit(f"{svg_path}: groups ink-1..ink-4 must all have paths")
    return lines


def main(src, dst):
    lines = convert(src)
    with open(dst, "w") as out:
        out.write("\n".join(lines) + "\n")
    print(f"{dst}: {len(lines)} strokes")
```

```kotlin
package com.summondemons.safely.ritual

/** Character range [start, end) of one syllable in the original text. */
data class SyllableSpan(val start: Int, val end: Int)

/**
 * Approximate Latin syllables for chant pacing and karaoke (ADR-0008). Not real
 * scansion: each diphthong (AE, OE, AU, EI, EU) or other single vowel is one nucleus;
 * a U after Q is a consonant; consonants join the following nucleus and the last
 * nucleus takes any trailing consonants.
 */
object LatinSyllables {
    private const val VOWELS = "AEIOUY"
    private val DIPHTHONGS = setOf("AE", "OE", "AU", "EI", "EU")
    private val WORD = Regex("[A-Za-z]+")

    fun count(text: String): Int = spans(text).size

    fun spans(text: String): List<SyllableSpan> =
        WORD.findAll(text).flatMap { wordSpans(it.value.uppercase(), it.range.first) }.toList()

    private fun wordSpans(word: String, offset: Int): List<SyllableSpan> {
        val nucleusEnds = mutableListOf<Int>() // exclusive end of each nucleus
        var i = 0
        while (i < word.length) {
            if (isVowel(word, i)) {
                val diphthong = i + 1 < word.length && word.substring(i, i + 2) in DIPHTHONGS
                i += if (diphthong) 2 else 1
                nucleusEnds += i
            } else {
                i++
            }
        }
        if (nucleusEnds.isEmpty()) return listOf(SyllableSpan(offset, offset + word.length))
        var start = 0
        return nucleusEnds.mapIndexed { k, nucleusEnd ->
            val end = if (k == nucleusEnds.lastIndex) word.length else nucleusEnd
            SyllableSpan(offset + start, offset + end).also { start = end }
        }
    }

    private fun isVowel(word: String, i: Int): Boolean =
        word[i] in VOWELS && !(word[i] == 'U' && i > 0 && word[i - 1] == 'Q')
}
```

```kotlin
package com.summondemons.safely.ritual

import com.summondemons.safely.ritual.RitualConfig.ANALYSIS_RATE
import com.summondemons.safely.ritual.RitualConfig.ONSET_RATIO
import com.summondemons.safely.ritual.RitualConfig.ONSET_REARM_RATIO
import com.summondemons.safely.ritual.RitualConfig.ONSET_WINDOW_FRAMES
import com.summondemons.safely.ritual.RitualConfig.VOICE_MAX_HZ
import com.summondemons.safely.ritual.RitualConfig.VOICE_MIN_HZ
import com.summondemons.safely.ritual.RitualConfig.VOICE_RMS_FLOOR
import com.summondemons.safely.ritual.RitualConfig.VOICING_MIN_CORRELATION
import kotlin.math.sqrt

/** One analysed 20 ms mic frame (ADR-0008). */
data class VoiceFrame(val rms: Double, val voiced: Boolean, val onset: Boolean) {
    companion object {
        val SILENT = VoiceFrame(0.0, voiced = false, onset = false)
    }
}

/**
 * Turns consecutive PCM16 frames into [VoiceFrame]s. Stateful (keeps the previous frame
 * and a short RMS history) but pure: no Android types.
 * - voiced: loud enough and periodic at a voice pitch (70–400 Hz) over the last 40 ms.
 * - onset: a voiced energy rise while armed; re-arms after a dip or an unvoiced frame.
 */
class VoiceAnalyzer(val sampleRate: Int) {
    private val stride = maxOf(1, sampleRate / ANALYSIS_RATE)
    private val minLag = sampleRate / VOICE_MAX_HZ
    private val maxLag = sampleRate / VOICE_MIN_HZ
    private var previous = ShortArray(0)
    private val recent = ArrayDeque<Double>()
    private var armed = true
    private var peak = 0.0

    fun analyze(samples: ShortArray, count: Int): VoiceFrame {
        val current = samples.copyOf(count)
        val level = rms(current, count)
        val window = previous + current
        previous = current
        val voiced = level > VOICE_RMS_FLOOR && periodicity(window) >= VOICING_MIN_CORRELATION

        val floor = recent.minOrNull() ?: 0.0
        var onset = false
        if (armed && voiced && level >= ONSET_RATIO * floor) {
            onset = true
            armed = false
            peak = level
        } else if (!armed) {
            peak = maxOf(peak, level)
            if (!voiced || level < ONSET_REARM_RATIO * peak) armed = true
        }
        recent.addLast(level)
        if (recent.size > ONSET_WINDOW_FRAMES) recent.removeFirst()
        return VoiceFrame(level, voiced, onset)
    }

    /** Highest normalized autocorrelation over the voice-pitch lags, in [-1, 1]. */
    private fun periodicity(x: ShortArray): Double {
        val upper = minOf(maxLag, x.size / 2)
        var best = 0.0
        var lag = minLag
        while (lag <= upper) {
            var num = 0.0
            var e1 = 0.0
            var e2 = 0.0
            var i = 0
            while (i < x.size - lag) {
                val a = x[i].toDouble()
                val b = x[i + lag].toDouble()
                num += a * b
                e1 += a * a
                e2 += b * b
                i += stride
            }
            if (e1 > 0.0 && e2 > 0.0) best = maxOf(best, num / sqrt(e1 * e2))
            lag += stride
        }
        return best
    }
}
```

```kotlin
/** Signed shortest turn from [from] to [to], in (-180, 180]; positive = clockwise (turn right). */
fun signedDelta(from: Float, to: Float): Float {
    val delta = ((to - from) % 360f + 540f) % 360f - 180f
    return if (delta == -180f) 180f else delta
}

/** Which way to turn to face [target]; null when the heading is unknown or already aligned. */
fun turnDirection(azimuth: Float?, target: Float): TurnDirection? = when {

    signedDelta(azimuth, target) > 0f -> TurnDirection.Right
```

```kotlin
package com.summondemons.safely.ritual

import com.summondemons.safely.ritual.RitualConfig.CLIMAX_MS
import com.summondemons.safely.ritual.RitualConfig.DRIFT_GRACE_MS
import com.summondemons.safely.ritual.RitualConfig.ONSET_REFRACTORY_MS
import com.summondemons.safely.ritual.RitualConfig.PHRASE_COUNT

enum class RitualPhase { Seeking, Locking, Chanting, Wavering, Climax, Done }

/** One 20 ms tick: the latest heading (null = unknown) and the analysed mic frame. */
data class RitualInput(val azimuth: Float?, val voice: VoiceFrame)

/** What happened during a step; the UI turns these into haptics and sounds. */
sealed interface RitualEffect {
    data object ProximityTick : RitualEffect
    data object Locked : RitualEffect
    data object SyllableLit : RitualEffect
    data class PhraseComplete(val phrase: Int) : RitualEffect
    data object DriftWarning : RitualEffect
    data object Resumed : RitualEffect
    data object PhraseLost : RitualEffect
    data object ClimaxStart : RitualEffect
    data object Summoned : RitualEffect
}

data class RitualState(
    val target: Float,
    /** Syllables per phrase: exactly [PHRASE_COUNT] entries, each ≥ 1. */
    val syllables: List<Int>,
    val phase: RitualPhase = RitualPhase.Seeking,
    val azimuth: Float? = null,
    /** Phrases completed so far (0..4). */
    val phrase: Int = 0,
    /** Syllables lit in the current phrase. */
    val lit: Int = 0,
    /** Time spent in the current Locking, Wavering or Climax phase. */
    val phaseMs: Long = 0L,
    val sinceSyllableMs: Long = ONSET_REFRACTORY_MS,
    val voicedRunMs: Long = 0L,
    /** Last 5° proximity bucket while seeking; null when out of range or unknown. */
    val proximityBucket: Int? = null,
) {
    init {
        require(syllables.size == PHRASE_COUNT) { "need exactly $PHRASE_COUNT phrases" }
        require(syllables.all { it >= 1 }) { "every phrase needs at least one syllable" }
    }

    val aligned: Boolean get() = azimuth != null && isAligned(azimuth, target)

    /** Sigil ink in [0, 1] (ADR-0009). */
    val inkProgress: Float
        get() = if (phrase >= PHRASE_COUNT) 1f else (phrase + lit.toFloat() / syllables[phrase]) / PHRASE_COUNT

    val graceFraction: Float
        get() = if (phase == RitualPhase.Wavering) (phaseMs.toFloat() / DRIFT_GRACE_MS).coerceIn(0f, 1f) else 0f

    val climaxFraction: Float
        get() = when (phase) {
            RitualPhase.Climax -> (phaseMs.toFloat() / CLIMAX_MS).coerceIn(0f, 1f)
            RitualPhase.Done -> 1f
            else -> 0f
        }

    companion object {
        fun start(target: Float, phrases: List<String>): RitualState =
            RitualState(target, phrases.map { LatinSyllables.count(it).coerceAtLeast(1) })
    }
}

data class Step(val state: RitualState, val effects: List<RitualEffect> = emptyList())
```

```kotlin
package com.summondemons.safely.ritual

import com.summondemons.safely.ritual.RitualConfig.FRAME_MS
import com.summondemons.safely.ritual.RitualConfig.LOCK_HOLD_MS
import com.summondemons.safely.ritual.RitualConfig.ONSET_REFRACTORY_MS
import com.summondemons.safely.ritual.RitualConfig.PROXIMITY_RANGE_DEG
import com.summondemons.safely.ritual.RitualConfig.PROXIMITY_STEP_DEG

/** Pure Ritual 2.0 rules (ADR-0008): one call per 20 ms tick. */
object RitualEngine {

    fun step(state: RitualState, input: RitualInput): Step {
        if (state.phase == RitualPhase.Done) return Step(state)
        val s = state.copy(azimuth = input.azimuth)
        return when (s.phase) {
            RitualPhase.Seeking, RitualPhase.Locking -> seek(s)
            RitualPhase.Chanting -> chant(s, input.voice)
            RitualPhase.Wavering -> waver(s)
            RitualPhase.Climax -> climax(s)
            RitualPhase.Done -> Step(s)
        }
    }

    private fun seek(s: RitualState): Step {
        val effects = mutableListOf<RitualEffect>()
        val bucket = s.azimuth?.let { proximityBucket(angularDistance(it, s.target)) }
        val previous = s.proximityBucket
        if (bucket != null && (previous == null || bucket < previous)) effects += RitualEffect.ProximityTick
        if (!s.aligned) {
            return Step(s.copy(phase = RitualPhase.Seeking, phaseMs = 0L, proximityBucket = bucket), effects)
        }
        val held = (if (s.phase == RitualPhase.Locking) s.phaseMs else 0L) + FRAME_MS
        if (held < LOCK_HOLD_MS) {
            return Step(s.copy(phase = RitualPhase.Locking, phaseMs = held, proximityBucket = bucket), effects)
        }
        effects += RitualEffect.Locked
        val chanting = s.copy(
            phase = RitualPhase.Chanting,
            phaseMs = 0L,
            proximityBucket = bucket,
            sinceSyllableMs = ONSET_REFRACTORY_MS,
            voicedRunMs = 0L,
        )
        return Step(chanting, effects)
    }

    private fun chant(s: RitualState, voice: VoiceFrame): Step = Step(s)

    private fun waver(s: RitualState): Step = Step(s)

    private fun climax(s: RitualState): Step = Step(s)

    private fun proximityBucket(distance: Float): Int? =
        if (distance <= PROXIMITY_RANGE_DEG) (distance / PROXIMITY_STEP_DEG).toInt() else null
}
```

```kotlin
        if (!s.aligned) {
            return Step(s.copy(phase = RitualPhase.Wavering, phaseMs = 0L, voicedRunMs = 0L), listOf(RitualEffect.DriftWarning))

        if (lit < s.syllables[s.phrase]) return Step(reset.copy(lit = lit), effects)

        effects += RitualEffect.PhraseComplete(s.phrase)

        if (phrase < PHRASE_COUNT) return Step(reset.copy(phrase = phrase, lit = 0), effects)

        effects += RitualEffect.ClimaxStart
        return Step(reset.copy(phase = RitualPhase.Climax, phrase = phrase, lit = 0, phaseMs = 0L), effects)
```

```kotlin
package com.summondemons.safely.sigil

/** One stroke of a sigil: its ink group (1..4) and SVG path data (ADR-0009). */
data class SigilStroke(val group: Int, val pathData: String)

/** Raw sigil format and ink math. Pure: no Android or Compose types. */
object SigilPaths {
    const val GROUPS = 4

    /** Lines are "<group> <path-data>"; blank lines are skipped; draw order is kept within a group. */
    fun parse(lines: List<String>): List<SigilStroke> = lines
        .map { it.trim() }
        .filter { it.isNotEmpty() }
        .map { line ->
            val space = line.indexOf(' ')
            require(space > 0) { "bad sigil line: $line" }
            val group = line.substring(0, space).toIntOrNull()
            require(group != null && group in 1..GROUPS) { "bad sigil group: $line" }
            SigilStroke(group, line.substring(space + 1).trim())
        }
        .sortedBy { it.group }

    /**
     * How much of each stroke (0..1) is inked at [inkProgress]. Group g inks over
     * [(g-1)/4, g/4]; inside a group, strokes ink one after another in proportion to [lengths].
     */
    fun inkFractions(strokes: List<SigilStroke>, lengths: List<Float>, inkProgress: Float): List<Float> {
        require(strokes.size == lengths.size) { "one length per stroke" }
        val groupProgress = FloatArray(GROUPS + 1) { g -> (inkProgress * GROUPS - (g - 1)).coerceIn(0f, 1f) }
        val budget = FloatArray(GROUPS + 1)
        strokes.forEachIndexed { i, stroke -> budget[stroke.group] += lengths[i] }
        for (g in 1..GROUPS) budget[g] *= groupProgress[g]
        val used = FloatArray(GROUPS + 1)
        return strokes.mapIndexed { i, stroke ->
            val length = lengths[i]
            val before = used[stroke.group]
            used[stroke.group] = before + length
            if (length <= 0f) {
                if (groupProgress[stroke.group] >= 1f) 1f else 0f
            } else {
                ((budget[stroke.group] - before) / length).coerceIn(0f, 1f)
            }
        }
    }
}
```

```kotlin
import android.media.AudioRecord
import android.media.MediaRecorder

import kotlinx.coroutines.flow.flow
import kotlinx.coroutines.flow.flowOn

/**
 * Mono PCM16 mic in [RitualConfig.FRAME_MS] frames. Tries 16 kHz, then 44.1 kHz (the
 * only rate every device must support). Only collected after RECORD_AUDIO is granted
 * (RitualViewModel). If no recorder starts, or reading fails, the flow just completes;
 * RitualViewModel then reports the mic as unavailable.
 */
class AndroidPcmSource : PcmSource {

    override fun frames(): Flow<PcmFrame> = flow {
        val recorder = openRecorder() ?: return@flow
        try {
            recorder.startRecording()
            if (recorder.recordingState != AudioRecord.RECORDSTATE_RECORDING) return@flow
            val rate = recorder.sampleRate
            val size = frameSize(rate)
            val buffer = ShortArray(size)
            while (currentCoroutineContext().isActive) {
                val read = recorder.read(buffer, 0, size) // blocks ~FRAME_MS
                if (read <= 0) break
                emit(PcmFrame(buffer.copyOf(read), read, rate))
            }
        } finally {
            recorder.release()
        }
    }.flowOn(Dispatchers.IO)

    @SuppressLint("MissingPermission") // Collected only once RECORD_AUDIO is granted.
    private fun openRecorder(): AudioRecord? {
        for (rate in SAMPLE_RATES) {
            val minBuffer = AudioRecord.getMinBufferSize(rate, CHANNEL, ENCODING)
            if (minBuffer <= 0) continue
            val recorder = try {
                AudioRecord(MediaRecorder.AudioSource.MIC, rate, CHANNEL, ENCODING, maxOf(minBuffer, frameSize(rate) * 4))
            } catch (e: SecurityException) {
                return null
            } catch (e: IllegalArgumentException) {
                continue
            }
            if (recorder.state == AudioRecord.STATE_INITIALIZED) return recorder
            recorder.release()
        }
        return null
    }

    private fun frameSize(sampleRate: Int): Int = (sampleRate * RitualConfig.FRAME_MS / 1_000).toInt()

    private companion object {
        val SAMPLE_RATES = listOf(16_000, 44_100)
        const val CHANNEL = AudioFormat.CHANNEL_IN_MONO
        const val ENCODING = AudioFormat.ENCODING_PCM_16BIT
    }
}
```

```kotlin
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), state.value)

    fun onMicPermission(granted: Boolean) = state.update { it.copy(micGranted = granted) }

    fun setSimulateHeading(on: Boolean) = state.update {
        if (on) it.copy(simulateHeading = true) else it.copy(simulateHeading = false, azimuth = null)
    }

    fun setHoldToChant(on: Boolean) {
        if (!on) holdFrames = 0
        state.update { it.copy(holdToChant = on) }
    }

    /** One 20 ms tick. Only this collector changes `ritual`, so read-then-update is safe. */
    private fun tick(micFrame: VoiceFrame) {
        val current = state.value
        val voice = if (current.holdToChant) syntheticVoice() else micFrame
        val step = RitualEngine.step(current.ritual, RitualInput(current.azimuth, voice))
        state.update { it.copy(ritual = step.state, micLevel = smoothMicLevel(it.micLevel, voice.rms)) }
        step.effects.forEach { _effects.tryEmit(it) }
    }

    /** Debug "Hold to Chant": continuous voicing with an onset every ~240 ms. */
    private fun syntheticVoice(): VoiceFrame =
        VoiceFrame(HOLD_TO_CHANT_RMS, voiced = true, onset = holdFrames++ % HOLD_TO_CHANT_ONSET_FRAMES == 0)

    /** Mic frames → analysed voice; if the mic dies (error or end), flag it and fall back to silence. */
    private fun micFrames(): Flow<VoiceFrame> = flow {
        var analyzer: VoiceAnalyzer? = null
        pcmSource.frames().collect { frame ->
            val current = analyzer?.takeIf { it.sampleRate == frame.sampleRate }
                ?: VoiceAnalyzer(frame.sampleRate).also { analyzer = it }
            emit(current.analyze(frame.samples, frame.count))
        }
    }
        .onStart { state.update { it.copy(micUnavailable = false) } }
        .catch { }
        .onCompletion { cause ->
            // cause != null only on cancellation (permission change, screen gone): not a mic failure.
            if (cause == null) {
                state.update { it.copy(micUnavailable = true) }
                emitAll(silentFrames())
            }
        }

    private fun silentFrames(): Flow<VoiceFrame> = flow {
        while (true) {
            delay(FRAME_MS)
            emit(VoiceFrame.SILENT)
        }
    }

    companion object {
        private const val EFFECT_BUFFER = 64

        fun factory(demon: Demon, headingSource: HeadingSource, pcmSource: PcmSource): ViewModelProvider.Factory =
            viewModelFactory { initializer { RitualViewModel(demon, headingSource, pcmSource) } }
    }
}
```

```kotlin
            context.getSystemService(VibratorManager::class.java)?.defaultVibrator
        } else {
            context.getSystemService(Vibrator::class.java)
        }
        return vibrator?.takeIf { it.hasVibrator() }
    }

    private fun predefined(context: Context, effectId: Int, fallbackMs: Long) {
        val vibrator = vibrator(context) ?: return

            Build.VERSION.SDK_INT >= Build.VERSION_CODES.O ->
                vibrator.vibrate(VibrationEffect.createOneShot(fallbackMs, VibrationEffect.DEFAULT_AMPLITUDE))
            else -> @Suppress("DEPRECATION") vibrator.vibrate(fallbackMs)
        }
    }

        val vibrator = vibrator(context) ?: return
        when {

            Build.VERSION.SDK_INT >= Build.VERSION_CODES.O -> vibrator.vibrate(VibrationEffect.createWaveform(fallback, -1))
            else -> @Suppress("DEPRECATION") vibrator.vibrate(fallback, -1)
        }
    }
```

```kotlin
import android.content.Context
import android.media.AudioAttributes
import android.media.AudioFocusRequest
import android.media.AudioManager
import android.media.MediaPlayer
import android.media.SoundPool
import android.os.Build
import androidx.annotation.RawRes
import com.summondemons.safely.R

/** One-shot cues (SoundPool) plus the demon's looping ambient bed (MediaPlayer). Main thread only. */
class RitualSounds(context: Context, @RawRes bed: Int) {

    enum class Cue(@param:RawRes val res: Int) {
        Chime1(R.raw.chime_1), Chime2(R.raw.chime_2), Chime3(R.raw.chime_3), Chime4(R.raw.chime_4),
        Lock(R.raw.lock), Riser(R.raw.riser), Boom(R.raw.boom);

        companion object {
            fun chime(phrase: Int): Cue = listOf(Chime1, Chime2, Chime3, Chime4)[phrase.coerceIn(0, 3)]
        }
    }

    private val appContext = context.applicationContext
    private val attributes = AudioAttributes.Builder()
        .setUsage(AudioAttributes.USAGE_GAME)
        .setContentType(AudioAttributes.CONTENT_TYPE_SONIFICATION)
        .build()
    private val pool = SoundPool.Builder().setMaxStreams(MAX_STREAMS).setAudioAttributes(attributes).build()
    private val ids: Map<Cue, Int> = Cue.entries.associateWith { pool.load(appContext, it.res, 1) }
    private val bedPlayer: MediaPlayer? = try {
        MediaPlayer.create(appContext, bed)?.apply {
            isLooping = true
            setVolume(0f, 0f)
        }
    } catch (e: Exception) {
        null
    }
    private var focusRequest: AudioFocusRequest? = null
    private var focusLost = false
    private var bedVolume = 0f
    private var released = false
    private val audioManager: AudioManager? = appContext.getSystemService(AudioManager::class.java)
    private val focusListener = AudioManager.OnAudioFocusChangeListener { change ->
        when (change) {
            AudioManager.AUDIOFOCUS_LOSS, AudioManager.AUDIOFOCUS_LOSS_TRANSIENT -> {
                focusLost = true
                bedPlayer?.takeIf { it.isPlaying }?.pause()
            }
            AudioManager.AUDIOFOCUS_GAIN -> {
                focusLost = false
                if (bedVolume > 0f) bedPlayer?.start()
            }
        }
    }
    fun play(cue: Cue) {
        if (released) return
        ids[cue]?.let { pool.play(it, 1f, 1f, 1, 0, 1f) }
    }

    /** Fades the bed to [to] (0..1); starts it when rising from silence, pauses it at 0. Cancellable. */
    suspend fun fadeBed(to: Float, durationMs: Long) {
        val player = bedPlayer ?: return
        if (released) return
        if (to > 0f && !player.isPlaying && !focusLost && requestFocus()) player.start()
        val from = bedVolume
        val steps = (durationMs / FADE_STEP_MS).coerceAtLeast(1)
        for (i in 1..steps) {
            if (released) return
            bedVolume = from + (to - from) * i / steps
            player.setVolume(bedVolume, bedVolume)
            delay(FADE_STEP_MS)
        }
        if (to == 0f && player.isPlaying) player.pause()
    }

    fun stopBed() {
        if (released) return
        bedVolume = 0f
        bedPlayer?.takeIf { it.isPlaying }?.pause()
        abandonFocus()
    }

    fun release() {
        if (released) return
        stopBed()
        released = true
        pool.release()
        bedPlayer?.release()
    }

    private fun requestFocus(): Boolean {
        val manager = audioManager ?: return true
        val result = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            val request = AudioFocusRequest.Builder(AudioManager.AUDIOFOCUS_GAIN_TRANSIENT)
                .setAudioAttributes(attributes)
                .setOnAudioFocusChangeListener(focusListener)
                .build()
            focusRequest = request
            manager.requestAudioFocus(request)
        } else {
            @Suppress("DEPRECATION")
            manager.requestAudioFocus(focusListener, AudioManager.STREAM_MUSIC, AudioManager.AUDIOFOCUS_GAIN_TRANSIENT)
        }
        return result == AudioManager.AUDIOFOCUS_REQUEST_GRANTED
    }

    private fun abandonFocus() {
        val manager = audioManager ?: return
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            focusRequest?.let { manager.abandonAudioFocusRequest(it) }
            focusRequest = null
        } else {
            @Suppress("DEPRECATION")
            manager.abandonAudioFocus(focusListener)
        }
    }

    private companion object {
        const val MAX_STREAMS = 4
        const val FADE_STEP_MS = 50L
    }
}
```

```kotlin
fun RitualFeedback(effects: Flow<RitualEffect>, @RawRes bed: Int) {

    val sounds = remember(bed) { RitualSounds(context, bed) }
    DisposableEffect(sounds) {
        onDispose { Handler(Looper.getMainLooper()).postDelayed({ sounds.release() }, RELEASE_DELAY_MS) }

    LifecycleEventEffect(Lifecycle.Event.ON_STOP) { sounds.stopBed() }

    LaunchedEffect(effects, sounds) {

        fun fadeBed(to: Float, ms: Long) {
            fade?.cancel()
            fade = launch { sounds.fadeBed(to, ms) }
        }
        effects.collect { effect ->
            when (effect) {
                RitualEffect.ProximityTick -> Haptics.tick(context)
                RitualEffect.Locked -> {
                    Haptics.clunk(context)
                    sounds.play(Cue.Lock)
                    fadeBed(BED_VOLUME, FADE_IN_MS)
                }
                RitualEffect.SyllableLit -> Haptics.syllable(context)
                is RitualEffect.PhraseComplete -> {
                    Haptics.chime(context)
                    sounds.play(Cue.chime(effect.phrase))
                }
                RitualEffect.DriftWarning -> {
                    Haptics.warn(context)
                    fadeBed(BED_DUCKED, DUCK_MS)
                }
                RitualEffect.Resumed -> fadeBed(BED_VOLUME, DUCK_MS)
                RitualEffect.PhraseLost -> {
                    Haptics.warn(context)
                    fadeBed(0f, FADE_OUT_MS)
                }
                RitualEffect.ClimaxStart -> {
                    Haptics.crescendo(context)
                    sounds.play(Cue.Riser)
                    fadeBed(1f, SWELL_MS)
                }
                RitualEffect.Summoned -> {
                    Haptics.success(context)
                    sounds.play(Cue.Boom)
                    fadeBed(0f, FADE_OUT_MS)
                }
            }
        }
    }
```

```kotlin
 * Deterministic drifting particles. [converge] in 0..1 pulls every particle to the
 * centre (climax). Draws nothing when motion is reduced.

fun ParticleField(

        val t = time / 1_000f

            val cycle = (p.phase + t * p.speed * style.rise) % 1f // 0 = bottom, 1 = top
            val x = p.x * size.width + sin(t * SWAY_RATE + p.swayPhase) * style.sway.toPx()
            val y = size.height * (1f - cycle)
            val at = Offset(lerp(x, center.x, converge), lerp(y, center.y, converge))
            val alpha = sin(cycle * PI).toFloat() * style.alpha * color.alpha
            val radius = (style.minRadius + style.radiusRange * p.size).toPx() * (1f - 0.5f * converge)
            when (style) {
                ParticleStyle.Embers -> drawCircle(color.copy(alpha = alpha), radius, at)
                ParticleStyle.Smoke -> drawCircle(
                    Brush.radialGradient(listOf(color.copy(alpha = alpha), Color.Transparent), center = at, radius = radius),
                    radius,
                    at,
                )
            }
        }
    }
```

```kotlin
/** Rising heat streaks tinted with the accent, strongest near the bottom. Premultiplied output. */
private const val HAZE_AGSL = """
uniform float2 size;
uniform float time;
layout(color) uniform half4 tint;

half4 main(float2 p) {
    float2 uv = p / size;
    float wave = 0.5 * sin(uv.x * 18.0 + time * 1.3) + 0.5 * sin(uv.x * 7.0 - time * 0.7 + uv.y * 4.0);
    float rise = fract(uv.y * 3.0 + time * 0.15 + wave * 0.08);
    float streak = smoothstep(0.0, 0.5, rise) * (1.0 - smoothstep(0.5, 1.0, rise));
    float a = streak * 0.22 * uv.y;
    return half4(tint.rgb * a, a);
}
"""

/** Wobbles whatever it is applied to, like air over a fire. */
private const val DISTORT_AGSL = """
uniform shader content;
uniform float time;
uniform float strength;

half4 main(float2 p) {
    float dx = sin(p.y * 0.08 + time * 3.1) * strength * 0.6;
    float dy = sin(p.y * 0.05 + time * 2.0) * strength * 0.3;
    return content.eval(p + float2(dx, dy));
}
"""

private const val BREATH_SECONDS = 4f
private const val FALLBACK_ALPHA = 0.18f
private val DistortionStrength = 2.dp

/** Accent heat haze overlay: AGSL on API 33+, a slowly breathing gradient below. */
@Composable
fun HeatShimmer(color: Color, modifier: Modifier = Modifier) {
    if (LocalReduceMotion.current) return
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
        ShaderHaze(color, modifier)
    } else {
        val time by rememberFrameTimeMs()
        Canvas(modifier) {
            val breath = 0.5f + 0.5f * sin(time / 1_000f * 2f * PI.toFloat() / BREATH_SECONDS)
            drawRect(Brush.verticalGradient(listOf(Color.Transparent, color.copy(alpha = FALLBACK_ALPHA * breath))))
        }
    }
}

@RequiresApi(Build.VERSION_CODES.TIRAMISU)
@Composable
private fun ShaderHaze(color: Color, modifier: Modifier) {
    val shader = remember { RuntimeShader(HAZE_AGSL) }
    val time by rememberFrameTimeMs()
    Canvas(modifier) {
        shader.setFloatUniform("size", size.width, size.height)
        shader.setFloatUniform("time", time / 1_000f)
        shader.setColorUniform("tint", color.toArgb())
        drawRect(ShaderBrush(shader))
    }
}

/** Applies a gentle heat distortion to [content] on API 33+; plain content elsewhere or with reduced motion. */
@Composable
fun HeatDistorted(modifier: Modifier = Modifier, content: @Composable () -> Unit) {
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU && !LocalReduceMotion.current) {
        Distorted(modifier, content)
    } else {
        Box(modifier) { content() }
    }
}

@RequiresApi(Build.VERSION_CODES.TIRAMISU)
@Composable
private fun Distorted(modifier: Modifier, content: @Composable () -> Unit) {
    val shader = remember { RuntimeShader(DISTORT_AGSL) }
    val time by rememberFrameTimeMs()
    val strength = with(LocalDensity.current) { DistortionStrength.toPx() }
    Box(
        modifier.graphicsLayer {
            shader.setFloatUniform("time", time / 1_000f)
            shader.setFloatUniform("strength", strength)
            renderEffect = RenderEffect.createRuntimeShaderEffect(shader, "content").asComposeRenderEffect()
        },
    ) { content() }
}
```

```kotlin
import android.hardware.Sensor
import android.hardware.SensorEvent
import android.hardware.SensorEventListener
import android.hardware.SensorManager
import androidx.compose.runtime.Composable
import androidx.compose.runtime.DisposableEffect
import androidx.compose.runtime.State
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.remember

import androidx.compose.ui.platform.LocalDensity
import androidx.compose.ui.unit.Dp
import androidx.compose.ui.unit.dp

private val MaxParallax = 12.dp
private const val SMOOTHING = 0.15f
/** How fast the resting pose follows the current pose, so a new grip re-centres. */
private const val RECENTER = 0.01f

/**
 * Small offset that follows device tilt (TYPE_GAME_ROTATION_VECTOR). Zero when motion is
 * reduced or the sensor is missing. Read `.value` inside `graphicsLayer` to avoid recomposition.
 */
@Composable
fun rememberParallax(maxOffset: Dp = MaxParallax): State<Offset> {
    val offset = remember { mutableStateOf(Offset.Zero) }
    val reduceMotion = LocalReduceMotion.current
    val context = LocalContext.current
    val maxPx = with(LocalDensity.current) { maxOffset.toPx() }
    DisposableEffect(reduceMotion, maxPx) {
        val manager = context.getSystemService(SensorManager::class.java)
        val sensor = manager?.getDefaultSensor(Sensor.TYPE_GAME_ROTATION_VECTOR)
        if (reduceMotion || manager == null || sensor == null) {
            offset.value = Offset.Zero
            return@DisposableEffect onDispose { }
        }
        val matrix = FloatArray(9)
        val angles = FloatArray(3)
        var rest: FloatArray? = null
        val listener = object : SensorEventListener {
            override fun onSensorChanged(event: SensorEvent) {
                SensorManager.getRotationMatrixFromVector(matrix, event.values)
                SensorManager.getOrientation(matrix, angles)
                val base = rest ?: angles.copyOf().also { rest = it }
                val target = parallaxOffset(angles[1] - base[1], angles[2] - base[2], maxPx)
                offset.value = lerp(offset.value, target, SMOOTHING)
                for (i in base.indices) base[i] += (angles[i] - base[i]) * RECENTER
            }

            override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) = Unit
        }
        manager.registerListener(listener, sensor, SensorManager.SENSOR_DELAY_GAME)
        onDispose { manager.unregisterListener(listener) }
    }
    return offset
}
```

```kotlin
        val strokes = SigilPaths.parse(lines)
        val paths = strokes.map { PathParser().parsePathString(it.pathData).toPath() }

/**
 * The demon's vector sigil (ADR-0009). [inkProgress] inks the glyph group by group;
 * [ringProgress] draws the double ring and rim letters ([rimText]); the glow widens and
 * brightens with [micLevel]; [flicker] scales the alpha (drift warning).
 */
@Composable
fun InkedSigil(
    @RawRes sigil: Int,
    inkProgress: Float,
    accent: Color,
    rimText: String,
    modifier: Modifier = Modifier,
    ringProgress: Float = 1f,
    micLevel: Float = 0f,
    flicker: Float = 1f,
) {
    val loaded = rememberSigil(sigil)
    val ink by animateFloatAsState(inkProgress, tween(INK_ANIM_MS), label = "sigilInk")
    val fractions = remember(loaded, ink) { SigilPaths.inkFractions(loaded.strokes, loaded.lengths, ink) }
    val textMeasurer = rememberTextMeasurer()
    val letterStyle = MaterialTheme.typography.titleLarge
    val glow = accent.copy(alpha = (GLOW_ALPHA + GLOW_MIC_ALPHA * micLevel) * flicker)
    val core = accent.copy(alpha = accent.alpha * flicker)
    Box(modifier) {
        Canvas(Modifier.fillMaxSize().blur(GlowBlur, BlurredEdgeTreatment.Unbounded)) {
            drawSigil(loaded, fractions, glow, STROKE * (GLOW_WIDTH + GLOW_MIC_WIDTH * micLevel), ringProgress)
        }
        Canvas(Modifier.fillMaxSize()) {
            drawSigil(loaded, fractions, core, STROKE, ringProgress)
            drawRim(textMeasurer, rimText, letterStyle, core, ringProgress)
        }
    }

/** Glyph strokes and rings, drawn in viewBox units scaled to fit. */
private fun DrawScope.drawSigil(sigil: LoadedSigil, fractions: List<Float>, color: Color, width: Float, ringProgress: Float) {
    val unit = size.minDimension / VIEWBOX
    val origin = Offset((size.width - VIEWBOX * unit) / 2f, (size.height - VIEWBOX * unit) / 2f)
    translate(origin.x, origin.y) {
        scale(unit, unit, pivot = Offset.Zero) {
            val stroke = Stroke(width, cap = StrokeCap.Round, join = StrokeJoin.Round)
            val measure = PathMeasure()
            sigil.paths.forEachIndexed { i, path ->
                val fraction = fractions[i]
                if (fraction <= 0f) return@forEachIndexed
                val inked = if (fraction >= 1f) {
                    path
                } else {
                    Path().also {
                        measure.setPath(path, false)
                        measure.getSegment(0f, sigil.lengths[i] * fraction, it, true)
                    }
                }
                drawPath(inked, color, style = stroke)
            }
            if (ringProgress > 0f) {
                val sweep = 360f * ringProgress
                val ringStroke = Stroke(RING_STROKE * width / STROKE, cap = StrokeCap.Round)
                for (radius in listOf(OUTER_RING, INNER_RING)) {
                    drawArc(
                        color, startAngle = -90f, sweepAngle = sweep, useCenter = false,
                        topLeft = Offset(VIEWBOX / 2 - radius, VIEWBOX / 2 - radius),
                        size = Size(radius * 2, radius * 2), style = ringStroke,
                    )
                }
            }
        }
    }
}

/** Rim letters spaced evenly around the ring, appearing one by one with [ringProgress]. */
private fun DrawScope.drawRim(measurer: TextMeasurer, text: String, style: TextStyle, color: Color, ringProgress: Float) {
    val letters = text.filterNot { it.isWhitespace() }
    if (letters.isEmpty() || ringProgress <= 0f) return
    val unit = size.minDimension / VIEWBOX
    val letterStyle = style.copy(fontSize = (RIM_LETTER_SIZE * unit).toSp())
    letters.forEachIndexed { i, letter ->
        val alpha = (ringProgress * letters.length - i).coerceIn(0f, 1f)
        if (alpha <= 0f) return@forEachIndexed
        val layout = measurer.measure(letter.toString(), letterStyle.copy(color = color.copy(alpha = color.alpha * alpha)))
        rotate(360f * i / letters.length, pivot = center) {
            drawText(
                layout,
                topLeft = Offset(
                    center.x - layout.size.width / 2f,
                    center.y - RIM_TEXT_RADIUS * unit - layout.size.height / 2f,
                ),
            )
        }
    }
}
```

```kotlin
fun AppNavHost(navController: NavHostController = rememberNavController()) {
    val demonViewModel: DemonViewModel = viewModel() // activity-scoped
    val appContext = LocalContext.current.applicationContext

    SharedTransitionLayout {
        CompositionLocalProvider(LocalSharedTransitionScope provides this) {
            NavHost(navController = navController, startDestination = Grimoire) {
                composable<Grimoire> {
                    ProvideDestinationScope {
                        val demons by demonViewModel.demons.collectAsStateWithLifecycle()
                        GrimoireScreen(
                            demons = demons,
                            onSummon = { id -> navController.navigate(Ritual(id)) },
                            onView = { id -> navController.navigate(Profile(id, isNewSummon = false)) },
                        )
                    }
                }

                composable<Ritual> { entry ->
                    ProvideDestinationScope {
                        val demon = demonViewModel.demon(entry.toRoute<Ritual>().demonId)
                        if (demon == null) {
                            LaunchedEffect(Unit) { navController.popBackStack() }
                        } else {
                            val factory = remember(demon) {
                                RitualViewModel.factory(demon, AndroidHeadingSource(appContext), AndroidPcmSource())
                            }
                            RitualScreen(
                                viewModel = viewModel(factory = factory),
                                onSummoned = {
                                    demonViewModel.unlock(demon.id)
                                    navController.navigate(Profile(demon.id, isNewSummon = true)) { popUpTo<Grimoire>() }
                                },
                                onAbort = dropUnlessResumed { navController.popBackStack() },
                            )
                        }
                    }
                }

                composable<Profile> { entry ->
                    ProvideDestinationScope {
                        val route = entry.toRoute<Profile>()
                        val demon = demonViewModel.demon(route.demonId)
                        if (demon == null) {
                            LaunchedEffect(Unit) { navController.popBackStack() }
                        } else {
                            ProfileScreen(
                                demon = demon,
                                isNewSummon = route.isNewSummon,
                                onDone = dropUnlessResumed { navController.popBackStack<Grimoire>(inclusive = false) },
                            )
                        }
                    }
                }
            }
        }
    }
}

@Composable
```
```kotlin
fun RitualScreen(
    viewModel: RitualViewModel,
    onSummoned: () -> Unit,
    onAbort: () -> Unit,
    modifier: Modifier = Modifier,
) {
    val state by viewModel.uiState.collectAsStateWithLifecycle()
    val context = LocalContext.current
    val activity = LocalActivity.current
    RitualFeedback(viewModel.effects, state.demon.ambientBed)

    // Ask once; re-check on every resume (e.g. after returning from Settings).
    var requested by rememberSaveable { mutableStateOf(false) }
    var permanentlyDenied by rememberSaveable { mutableStateOf(false) }
    var deniedBefore by rememberSaveable { mutableStateOf(false) }
    val launcher = rememberLauncherForActivityResult(ActivityResultContracts.RequestPermission()) { granted ->
        viewModel.onMicPermission(granted)
        // A first denial or a dismissed dialog also reports "no rationale"; only a repeat
        // denial without rationale means "don't ask again".
        permanentlyDenied = !granted && deniedBefore && activity != null &&
            !ActivityCompat.shouldShowRequestPermissionRationale(activity, Manifest.permission.RECORD_AUDIO)
        if (!granted) deniedBefore = true
    }
    LifecycleEventEffect(Lifecycle.Event.ON_RESUME) {
        val granted = ContextCompat.checkSelfPermission(context, Manifest.permission.RECORD_AUDIO) ==
            PackageManager.PERMISSION_GRANTED
        when {
            granted -> viewModel.onMicPermission(true)
            !requested -> {
                requested = true
                launcher.launch(Manifest.permission.RECORD_AUDIO)
            }
        }
    }

    val done = state.ritual.phase == RitualPhase.Done
    LaunchedEffect(done) {
        if (done) onSummoned()
    }

    RitualContent(
        state = state,
        permanentlyDenied = permanentlyDenied,
        onRetryPermission = { launcher.launch(Manifest.permission.RECORD_AUDIO) },
        onOpenSettings = {
            context.startActivity(
                Intent(Settings.ACTION_APPLICATION_DETAILS_SETTINGS, Uri.fromParts("package", context.packageName, null)),
            )
        },
        onSimulateHeadingChange = viewModel::setSimulateHeading,
        onHoldToChantChange = viewModel::setHoldToChant,
        onAbort = onAbort,
        modifier = modifier,
    )
}

private fun compassMode(phase: RitualPhase): CompassMode = when (phase) {

/** Sigil alpha multiplier: a nervous flicker while Wavering, steady otherwise. */
@Composable
private fun flickerAlpha(active: Boolean, reduceMotion: Boolean): Float {
    if (!active) return 1f
    if (reduceMotion) return FLICKER_MIN
    val time by rememberFrameTimeMs()
    return FLICKER_MIN + (1f - FLICKER_MIN) * abs(sin(time * FLICKER_RATE))
}

@Composable

    val direction = headingLabel(state.demon.ritualHeading)
    return when (state.ritual.phase) {
        RitualPhase.Seeking -> when (turnDirection(state.azimuth, state.demon.ritualHeading)) {
            TurnDirection.Left -> stringResource(R.string.hint_turn_left, direction)
            TurnDirection.Right -> stringResource(R.string.hint_turn_right, direction)
            null -> stringResource(R.string.hint_face, direction)
        }
        RitualPhase.Locking -> stringResource(R.string.hint_hold_steady)
        RitualPhase.Chanting -> if (state.micGranted == false && !state.holdToChant) {
            stringResource(R.string.hint_mic_needed)
        } else {
            stringResource(R.string.hint_chant)
        }
        RitualPhase.Wavering -> stringResource(R.string.hint_face_again, direction)
        RitualPhase.Climax, RitualPhase.Done -> stringResource(R.string.hint_summoning)
    }
}

/** Climax staging by [fraction]: dim, converge, flash, then the demon rises out of the sigil. */
@Composable
private fun ClimaxOverlay(demon: Demon, accent: Color, fraction: Float, reduceMotion: Boolean) {
    val colors = MaterialTheme.colorScheme
    val dim = segment(fraction, 0f, 0.3f)
    val converge = segment(fraction, 0f, 0.6f)
    val flash = if (reduceMotion) 0f else 1f - (abs(fraction - FLASH_PEAK) / FLASH_HALF_WIDTH).coerceIn(0f, 1f)
    val rise = if (reduceMotion) fraction else segment(fraction, 0.7f, 1f)
    val riseDistance = with(LocalDensity.current) { RiseDistance.toPx() }
    Box(
        Modifier.fillMaxSize().background(colors.surfaceContainerLowest.copy(alpha = CLIMAX_SCRIM_ALPHA * dim)),
        contentAlignment = Alignment.Center,
    ) {
        ParticleField(accent, ParticleStyle.Embers, Modifier.fillMaxSize(), count = CLIMAX_PARTICLES, converge = converge, seed = 29)
        if (flash > 0f) {
            Canvas(Modifier.fillMaxSize()) {
                drawRect(
                    Brush.radialGradient(
                        listOf(colors.onBackground.copy(alpha = flash), accent.copy(alpha = flash * FLASH_ACCENT_ALPHA), Color.Transparent),
                    ),
                )
            }
        }
        SharedDemonArt(
            demonId = demon.id,
            modifier = Modifier
                .fillMaxWidth(CUTOUT_WIDTH_FRACTION)
                .aspectRatio(CUTOUT_ASPECT)
                .graphicsLayer {
                    alpha = rise
                    val scale = lerp(RISE_START_SCALE, 1f, rise)
                    scaleX = scale
                    scaleY = scale
                    translationY = (1f - rise) * riseDistance
                },
        ) {
            DemonCutout(demon.cutoutArt, demon.name, accent, Modifier.fillMaxSize(), silhouette = 1f - rise)
```

```kotlin
@Composable
private fun DemonHeroPage(entry: DemonEntry, topPadding: Dp, onSummon: () -> Unit, onView: () -> Unit) {
```
