# i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Summon Demons Safely in English, Spanish, Brazilian Portuguese, Italian and French. Every translation is at most as long as its English source.

**Architecture:** All player text moves into Android string resources: `strings.xml` for the UI and a new `demons.xml` for demon lore and badges. `Demon`, `House` and `Calling` hold resource ids instead of English strings. A plain-JVM XML reader powers the tests: completeness, placeholders, length (with a reviewed exception list), and glyph coverage. Android selects the language from the device or from the per-app setting (Android 13+).

**Tech Stack:** Kotlin, Jetpack Compose (`stringResource`, `stringArrayResource`, `pluralStringResource`), AGP 9 (`generateLocaleConfig`, pseudo-locales, lint), JUnit 4, `javax.xml` DOM, `java.awt.Font`.

**Spec:** `docs/superpowers/specs/2026-10-20-i18n-design.md`. Read it first; this plan does not repeat its reasons.

**Conventions:** run commands from the repo root. Unit tests run with `./gradlew testDebugUnitTest`, with the working directory set to `app/`, so test paths start with `src/...`. Commits follow Conventional Commits and end with the `Co-Authored-By` line from the session. Never edit `reference/`.

`app/src/test/java/com/summondemons/safely/i18n/ResourceTexts.kt`:

```kotlin
package com.summondemons.safely.i18n

import com.summondemons.safely.R
import org.w3c.dom.Element
import java.io.File
import javax.xml.parsers.DocumentBuilderFactory

/** The text resources of one `values*` folder, read as plain JVM data (no Android runtime). */
data class ResourceTexts(
    val strings: Map<String, String>,
    val arrays: Map<String, List<String>>,
    /** Key → quantity ("one", "many", "other"…) → text. */
    val plurals: Map<String, Map<String, String>>,
    /** Keys marked `translatable="false"`. */
    val untranslatable: Set<String>,
) {
    val keys: Set<String> get() = strings.keys + arrays.keys + plurals.keys

    companion object {
        fun load(dir: File): ResourceTexts {
            val strings = mutableMapOf<String, String>()
            val arrays = mutableMapOf<String, List<String>>()
            val plurals = mutableMapOf<String, Map<String, String>>()
            val untranslatable = mutableSetOf<String>()
            val files = dir.listFiles { f -> f.extension == "xml" }.orEmpty().sortedBy { it.name }
            for (file in files) {
                val root = DocumentBuilderFactory.newInstance().newDocumentBuilder().parse(file).documentElement
                for (node in root.children()) {
                    val name = node.getAttribute("name")
                    if (node.getAttribute("translatable") == "false") untranslatable += name
                    when (node.tagName) {
                        "string" -> strings[name] = unescapeAndroid(node.textContent)
                        "string-array" -> arrays[name] = node.children("item").map { unescapeAndroid(it.textContent) }
                        "plurals" -> plurals[name] =
                            node.children("item").associate { it.getAttribute("quantity") to unescapeAndroid(it.textContent) }
                    }
                }
            }
            return ResourceTexts(strings, arrays, plurals, untranslatable)
        }

        private fun Element.children(tag: String? = null): List<Element> =
            (0 until childNodes.length).map { childNodes.item(it) }
                .filterIsInstance<Element>()
                .filter { tag == null || it.tagName == tag }
    }
}

/** Android string-resource text as shown on screen: outer quotes removed, backslash escapes resolved. */
fun unescapeAndroid(raw: String): String {
    val text = if (raw.length >= 2 && raw.startsWith('"') && raw.endsWith('"')) raw.substring(1, raw.length - 1) else raw
    val out = StringBuilder()
    var i = 0
    while (i < text.length) {
        val c = text[i]
        if (c == '\\' && i + 1 < text.length) {
            out.append(
                when (val next = text[i + 1]) {
                    'n' -> '\n'
                    't' -> '\t'
                    else -> next
                },
            )
            i += 2
        } else {
            out.append(c)
            i++
        }
    }
    return out.toString()
}

/** The `values*` folder of a shipped locale, from the module directory. */
fun valuesDir(qualifier: String? = null): File =
    File(if (qualifier == null) "src/main/res/values" else "src/main/res/values-$qualifier")

val english: ResourceTexts by lazy { ResourceTexts.load(valuesDir()) }

/** Resource name of a string resource id (Task 3 adds `R.plurals`, Task 4 adds `R.array`). */
fun resName(id: Int): String =
    listOf<Class<*>>(R.string::class.java)
        .firstNotNullOfOrNull { type -> type.fields.firstOrNull { it.getInt(null) == id }?.name }
        ?: error("No string resource with id $id")

/** English text of a string resource. */
fun en(id: Int): String = english.strings.getValue(resName(id))
```

`R.plurals` and `R.array` exist only once the first `<plurals>` (Task 3) and `<string-array>` (Task 4) are in `values/`. Those tasks extend the `listOf<Class<*>>(…)` list. Task 4 also adds:

```kotlin
/** English items of a string-array resource. */
fun enArray(id: Int): List<String> = english.arrays.getValue(resName(id))
```

```kotlin
package com.summondemons.safely.i18n

import java.awt.Font
import java.io.File

/** A translation longer than its English source. */
data class Overrun(val key: String, val length: Int, val english: Int)

/** A reviewed exception to the length rule (`length-exceptions.txt`). */
data class LengthException(val locale: String, val key: String, val reason: String)

private val PLACEHOLDER = Regex("%(\\d+\\$)?[-#+ 0,(]*\\d*(\\.\\d+)?[a-zA-Z%]")

private fun ResourceTexts.translatableKeys(): Set<String> = keys - untranslatable

/** Length in characters as a reader sees them (code points). */
private fun String.cpLength(): Int = codePointCount(0, length)

/** Every translatable English key exists, nothing extra does, arrays match in size, plurals have their forms. */
fun completeness(en: ResourceTexts, tr: ResourceTexts, requiredQuantities: Set<String>): List<String> {
    val expected = en.translatableKeys()
    val problems = mutableListOf<String>()
    (expected - tr.keys).sorted().forEach { problems += "missing: $it" }
    (tr.keys - expected).sorted().forEach { problems += "extra: $it" }
    for ((key, items) in en.arrays) {
        val translated = tr.arrays[key] ?: continue
        if (translated.size != items.size) problems += "$key: ${translated.size} items, English has ${items.size}"
    }
    for (key in en.plurals.keys) {
        val forms = tr.plurals[key] ?: continue
        (requiredQuantities - forms.keys).sorted().forEach { problems += "$key: missing quantity $it" }
    }
    return problems
}

private fun placeholdersOf(text: String): List<String> = PLACEHOLDER.findAll(text).map { it.value }.sorted().toList()

/** Each translated text uses the same format specifiers as its English source. */
fun placeholders(en: ResourceTexts, tr: ResourceTexts): List<String> {
    val problems = mutableListOf<String>()
    fun compare(key: String, english: String, translated: String) {
        val want = placeholdersOf(english)
        val got = placeholdersOf(translated)
        if (want != got) problems += "$key: placeholders $got, English has $want"
    }
    for ((key, text) in tr.strings) en.strings[key]?.let { compare(key, it, text) }
    for ((key, items) in tr.arrays) en.arrays[key]?.zip(items)?.forEach { (e, t) -> compare(key, e, t) }
    for ((key, forms) in tr.plurals) {
        val english = en.plurals[key]?.get("other") ?: continue
        forms.values.forEach { compare(key, english, it) }
    }
    return problems.distinct()
}

/** Texts longer than English: strings 1:1, array items by position, plural forms vs English's longest form. */
fun overLength(en: ResourceTexts, tr: ResourceTexts): List<Overrun> {
    val over = mutableListOf<Overrun>()
    for ((key, text) in tr.strings) {
        val english = en.strings[key] ?: continue
        if (text.cpLength() > english.cpLength()) over += Overrun(key, text.cpLength(), english.cpLength())
    }
    for ((key, items) in tr.arrays) {
        val english = en.arrays[key] ?: continue
        items.zip(english).forEachIndexed { i, (t, e) ->
            if (t.cpLength() > e.cpLength()) over += Overrun("$key[$i]", t.cpLength(), e.cpLength())
        }
    }
    for ((key, forms) in tr.plurals) {
        val longest = en.plurals[key]?.values?.maxOf { it.cpLength() } ?: continue
        forms.forEach { (quantity, t) ->
            if (t.cpLength() > longest) over += Overrun("$key#$quantity", t.cpLength(), longest)
        }
    }
    return over.sortedBy { it.key }
}

/**
 * Overruns must be listed exceptions; listed exceptions must still be needed and have a heading
 * `### <locale> · <key>` in docs/i18n/review.md.
 */
fun exceptionProblems(locale: String, over: List<Overrun>, exceptions: List<LengthException>, reviewText: String): List<String> {
    val listed = exceptions.filter { it.locale == locale }.associateBy { it.key }
    val problems = mutableListOf<String>()
    for (o in over) if (o.key !in listed) problems += "${o.key}: ${o.length} characters, English has ${o.english}"
    for ((key, _) in listed) {
        if (over.none { it.key == key }) problems += "$key: exception no longer needed"
        else if ("### $locale · $key" !in reviewText) problems += "$key: exception has no entry in docs/i18n/review.md"
    }
    return problems
}

fun loadExceptions(file: File): List<LengthException> =
    file.takeIf { it.isFile }?.readLines().orEmpty()
        .map { it.trim() }
        .filter { it.isNotEmpty() && !it.startsWith("#") }
        .map { line ->
            val parts = line.split(Regex("\\s+"), limit = 3)
            require(parts.size == 3) { "length-exceptions.txt: expected '<locale> <key> <reason>', got '$line'" }
            LengthException(parts[0], parts[1], parts[2])
        }

/** Letters in [text] that some font in [fonts] cannot draw. Punctuation and symbols are not checked. */
fun missingGlyphs(text: String, fonts: List<File>): List<String> {
    System.setProperty("java.awt.headless", "true")
    val loaded = fonts.map { it.name to Font.createFont(Font.TRUETYPE_FONT, it) }
    val letters = text.codePoints().toArray().filter { Character.isLetter(it) }.distinct()
    return loaded.flatMap { (name, font) ->
        letters.filterNot { font.canDisplay(it) }.map { "$name lacks '${String(Character.toChars(it))}'" }
    }
}
```

```markdown
# Translation style

Applies to every string in `values-*/strings.xml` and `values-*/demons.xml`, the store listings
and the privacy policy (i18n spec §6).

1. **Never longer than English**, counted in characters as `TranslationResourcesTest` counts
   them. If it cannot fit without losing the point, write the best version that does fit, add an
   entry to `docs/i18n/review.md`, and only then consider a length exception.
2. **Keep the joke, not the words.** Each line is comedy first. Replace an untranslatable pun
   with a local one of the same kind; log the swap in the review queue.
3. **Never give the player a gender.** Use imperatives and neutral phrasing ("Volte amanhã",
   not "Você está pronto"). Demons are male; agree with him.
4. **Leave alone:** demon names (Asmodeus, Astaroth, Amaymon, Astarte), planets (Sol, Venus),
   the Latin chant, "Summon Demons Safely".
5. **Glossary terms are fixed** (`docs/i18n/glossary.md`); use them everywhere, same form.
6. **Direction sentences** (`chant_face`, `badge_direction_text`, `chant_a11y_*`) must read
   correctly with all eight compass points; prefer phrasings with no article ("Cap : %1$s").
   Check with `DirectionSentencesReport`.
7. **Punctuation:** French « », a narrow no-break space before ! ? : ; and %; Spanish ¡ ¿;
   typographic apostrophes (’) as in the English source. Escape a straight apostrophe as `\'`.
8. **Register:** informal and playful (tu in French/Italian/Spanish; você in pt-BR), matching
   the English tone.
9. **Placeholders** (`%1$s`, `%2$d`) stay exactly as in English; their order in the sentence may
   change.
```
